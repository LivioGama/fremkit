# Contributing

Thanks for wanting to help. Where to start depends on what you have in mind:

- **A bug or an idea**: open an [issue](https://github.com/fdussert/fremkit/issues/new/choose).
  A question goes to [Q&A](https://github.com/fdussert/fremkit/discussions/categories/q-a).
- **A widget or a theme**: it belongs in the registry,
  [fremkit-sietch](https://github.com/fdussert/fremkit-sietch), not here. Start with
  [docs/writing-widgets.md](docs/writing-widgets.md) or [docs/themes.md](docs/themes.md).
- **A change to Fremkit itself**: [docs/contributing.md](docs/contributing.md) has the layout,
  the scripts and the conventions. Working with a coding agent? Point it at
  [AGENTS.md](AGENTS.md); it holds the rules agents tend to break.
- **A security issue**: see [SECURITY.md](SECURITY.md), not a public issue.

A pull request says what it changes and how to see it; the template asks for both.
